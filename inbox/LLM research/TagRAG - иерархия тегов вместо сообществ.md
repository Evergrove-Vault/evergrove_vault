# 📝 Overview
**TagRAG** строит граф знаний из *тегов*, а не из именованных сущностей и связей: извлекаются «объектные теги» с описаниями и организуются в иерархические цепочки предметных тегов («область → подобласть → объект»). Поиск идёт по цепочкам тегов, а новые материалы вставляются в существующий граф **без повторной кластеризации сообществ**. Первая версия — 18.10.2025, последняя (v3) — 02.05.2026, принято в Findings of ACL 2026.

> [!important] Чего нет в моих заметках
> В [[GraphRAG (Microsoft)]] иерархия строится алгоритмом Leiden по всему графу, а сводки сообществ пересобираются при изменении корпуса (см. [[GraphRAG (Microsoft)#Ограничения и риски]]). TagRAG показывает альтернативу, где иерархия задана предметными тегами и растёт вставкой.

# 💡 Как это работает

## Построение (три LLM-вызова на чанк)
1. Из чанка извлекаются **объектные теги** (ключевые слова предметной области) с описаниями и связями между ними.
2. Для объектных тегов генерируются **цепочки доменных тегов** до корневой области.
3. Цепочки сливаются в ориентированный ациклический граф по алгоритму, который избегает дублей и циклов; связь «has subdomain» ведёт от верхнего домена к нижнему.
Основной LLM построения в статье — небольшая **Qwen3-4B**.

## Сводки
Для каждого доменного тега строится сводка из двух частей: информация о домене по цепочке и специализированные знания о его объектах.

## Пополнение (инкремент)
- Новые объектные и доменные теги **добавляются к описаниям одноимённых тегов**.
- Для нового доменного знания старая и новая сводки одноимённого тега **пересуммируются**.
- Повторное выделение сообществ не нужно: цепочки встраиваются прямо в существующую структуру.

## Поиск
1. Косинусная близость запроса к сводкам доменных тегов (в экспериментах top-k = 3).
2. Достаются целые цепочки тегов для найденных доменов.
3. В контекст сначала кладутся сводки доменных тегов, затем сводки цепочек, пока не исчерпан лимит.

# 📊 Результаты (UltraDomain: Agriculture, CS, Law, Mix)
- Средний winning rate против baselines — **78.36%**; против NaiveRAG, GraphRAG и LightRAG — 82.85%.
- Эффективность относительно GraphRAG: построение примерно в **14.6×**, поиск в **1.9×**.
- Оценка LLM-судьями (GPT-4o-mini, Gemini 2.5 Pro, Claude Sonnet 4.5) по comprehensiveness, diversity, empowerment, overall; baselines — NaiveRAG, GraphRAG, LightRAG, MiniRAG.
