# 📝 Overview
Руководство с кодом: PDF разбирается на **элементы** (текст и изображения) постранично, текст эмбеддится моделью SentenceTransformers, изображения — CLIP, векторы идут в **две отдельные коллекции Qdrant**, а каждому элементу сохраняется имя файла и номер страницы. Полезно там, где важные сведения лежат в иллюстрациях, и как минимальный образец «провенанса каждого найденного фрагмента».

> [!important] Что уже есть и чего не хватает
> В [[hybrid RAG методы реализации часть 1#Multimodal RAG]] перечислены CLIP, BLIP и «OCR + Vision-модель», а в [[21 Chunking Strategies for RAG#6. Page-based chunking]] — совет «сохранять номер страницы и источник». Здесь это собрано в работающий сквозной пример с конкретными моделями и хранилищем.

# 💡 Как это работает
1. **Разбор PDF** (`pypdf`): по каждой странице берётся текст (`page.extract_text()`) и встроенные изображения (`page.images`); картинки меньше 16×16 пикселей отбрасываются, остальные приводятся к миниатюрам до 512×512.
2. **Текст**: рекурсивная нарезка на чанки, эмбеддинги `all-MiniLM-L6-v2` (SentenceTransformers).
3. **Изображения**: эмбеддинги CLIP `openai/clip-vit-large-patch14`.
4. **Хранение**: две коллекции Qdrant (текст и изображения), один общий коннектор, UUID в качестве первичных ключей.
5. **Провенанс**: для каждого чанка и картинки записываются `filename` и `page`, «so any retrieved result can be traced back to the exact source document and page».
6. **Запрос**: поиск по PDF по тексту или по образу; можно доставать связанные рисунки, диаграммы и подписи.

# ⚠️ Замечания (мои выводы из устройства пайплайна)
- Два разных пространства эмбеддингов (текст — MiniLM, картинки — CLIP): их оценки несравнимы напрямую, объединять выдачу надо через ранги, например по [[методы Reranking#Reciprocal Rank Fusion (RRF)]].
- CLIP плохо читает мелкий текст, таблицы и подписи на картинках, а `all-MiniLM-L6-v2` — англоцентричная модель; для русского корпуса это надо проверять.
- `extract_text` теряет разметку и таблицы: для них нужен структурный парсер ([[Docling - layout-aware парсинг документов]]).
- Провенанс здесь постраничный, без координат блока на странице.
- Альтернатива «страница как картинка» без отдельных пайплайнов для текста и рисунков: [[ColPali - поиск по картинкам страниц]].
